Chest card stat lines: four layouts

Real data (research/analysis/chest-item-stats.json) and the game's own colours and sizes. In game the card is drawn larger (UI scale); proportions match. v0.106 showed every stat line followed by an empty line (a div is already a line, and the <br/> after it added another). "safe" = only structures already shown on the card; "riskier"/"riskiest" = structures the game uses in its inventory tooltip but that we have not tried inside the card description.

safe A. Compact

Only <div css="font-text-caption-minor-white"> lines (already shown on the card in v0.106) with the extra <br/> removed, plus one <br/> before the item text.

riskier B. Two columns

Nested divs with the inventory tooltip's ItemTooltipStat2 classes (item-tooltip-stat-wrap2, item-tooltip-sub-stat-label-wrap; label kept on one line as the game does). Needs ItemTooltip2.css on the map page (the map page uses ItemTooltip2 widgets, so probably loaded) and flex rows inside the description.

riskiest C. Two columns + icons

As B plus item-tooltip-stat-icon2 cpp-<stat> icons. Icons here: the Defense shield, Movement Speed boot and Health heart are cut from your Witch's Earring inventory tooltip screenshot; the others (blank squares) come from the game's texture atlas in game, which this page cannot read.

safe D. Buff style (Abyss)

Abyss effect line in the tooltip's buff yellow (font-text-caption-minor-yellow, #ffd292), siphon note beige, "Also contains" gray. Same one-div lines as A, no icons. Surface cards: as B.
